# Data Analytics Tools

A collection of data analytics projects that demonstrate skills across Excel, Tableau, and Power BI. Each project covers the workflow from raw data through cleaning, transformation, analysis, and dashboarding.

## Repository Structure

| File | Description |
|---|---|
| `1.Bike_buyers_dataset.csv` | Original raw dataset (Project 1) |
| `2.Working_sheet.csv` | Cleaned and transformed working dataset (Project 1) |
| `3.Pivot_tables.pdf` | Pivot tables and charts built from the working dataset (Project 1) |
| `4.Dashboard-Excel_Bike_buyers_analysis.png` | Final dashboard built in Excel (Project 1) |
| `5. Tableau Dashboard- AirBnb_Listing_data_analysis.png` | Final Tableau dashboard, Airbnb listings (Project 2) |
| `6a.Data_professional_survey.csv` | Data professionals survey dataset, transformed (Project 3) |
| `6b.PowerBI_dashboard-Data_professional_survey.png` | Final Power BI dashboard, survey analysis (Project 3) |

## Projects

### Project 1: Bike Buyers Analysis (Excel)

Files 1 to 4 form one project that demonstrates Excel skills. It analyses customer demographics and purchasing behaviour to show which segments are most likely to buy a bike.

**Files:** `1.Bike_buyers_dataset.csv` → `2.Working_sheet.csv` → `3.Pivot_tables.pdf` → `4.Dashboard-Excel_Bike_buyers_analysis.png`

**Dataset columns:** ID, Marital Status, Gender, Income, Children, Education, Occupation, Home Owner, Cars, Commute Distance, Region, Age, Purchased Bike

**Skills demonstrated**
- Data cleaning, pivot tables, charts, conditional formatting, formulas, dashboard design.



### Project 2: Airbnb Listings Analysis (Tableau)

Interactive Tableau dashboard exploring Airbnb listing data.

**Files:** `5. Tableau Dashboard- AirBnb_Listing_data_analysis.png`

> **Note:** The source dataset is too large to include in this repository, so only the dashboard screenshot is provided.


### Project 3: Data Professionals Survey Analysis (Power BI)

Analysis of a survey of data professionals, covering role, salary,industry,favourite programminf language,survey questions. The dataset was cleaned and transformed before dashboarding.

**Files:** `6a.Data_professional_survey.csv` (raw dataset), `6b.PowerBI_dashboard-Data_professional_survey.png` (final dashboard)
